# 雷达单位与校准约定

这些参数用于游戏建模，不代表真实装备性能。

水平位置、距离及敌方平台/空中系统航迹的不确定度使用世界单位。`CombatPicture.Track`
是历史接口，其水平 `uncertainty` 使用米；创建测量、关联门限、转交空中数据链及
雷达绘图时通过 `uncertaintyMetersToWorld` 转换。不能因为属性同名就混用单位。
`surfaceEsmCue` 属于平台航迹，并不使用该米制接口。

无线电视距采用 `4.12 × (√雷达高度米 + √目标高度米)` 公里，再乘场景
`worldUnitsPerKm`。沙盒默认值为 10，所以旧公式中的 41.2 保持数值等价。
场景尺度传递到舰艇态势图、空中传感器及敌方平台传感器。

传感器与 Tacview 的历史高度约定为每单位 50 米，集中在
`SENSOR_ALTITUDE_METERS_PER_UNIT`，独立于水平尺度。飞行能量/气动模型的
`WORLD_ALTITUDE_TO_METERS = 100` 是另一套既有校准，本次不重调。

## RCS 因子

输入均为游戏有效平方米，四次方根公式由 `src/radar/model.ts` 维护。
各场景的标称距离已经采用不同的参考目标校准，不能仅凭输入字段同名就合并参考值。

| 配置 | 参考平方米 | 包络 | 消费位置与用途 |
| --- | ---: | --- | --- |
| shipSearch | 0.5 | 比值最低 0.05，无上限 | CombatPicture 舰载搜索的距离缩放，针对小目标校准 |
| airSearch | 8 | 比值最低 0.05，无上限 | 空中搜索的距离缩放，参考战斗机 |
| surfaceSearch | 10 | 比值最低 0.05，无上限 | 敌方平台搜索的距离缩放，既有小目标校准 |
| airSeeker | 8 | 因子 0.32–1.25 | 空中雷达导引头捕获概率，限制概率增益 |
| maritimeCue | 12000 | 比值最低 0.05，因子 0.22–1 | 外部海上目标线索的质量修正，参考大舰目标 |

海上线索因子不参与 `maxRange`，只小幅修正线索质量和误差椭圆。
这与舰艇搜索距离不是同一个观测量。本轮保持所有参考值与包络，避免隐含平衡改动。
将来重调时须分别验证探测距离、捕获概率和线索质量，不能统一套用概率包络。

`npm run verify:radar-model` 验证默认数值等价、非默认尺度、真实测量生成和全部五个
RCS 消费者接线；空中传感器、导引头及 Tacview 各自的回归继续保留。

## 俯视杂波与多普勒

空中传感器可通过目录的 `pulseDoppler` 开启简化滤波。目前 AN/AWG-9 和 N019
配置半宽 0.6 水平世界单位/秒、最低因子 0.25、最小俯视角 2 度。这些是游戏参数，
没有宣称对应真实带宽；其他传感器未配置时数值完全保持旧行为。

计算相对径向闭合率，并扣除地面/海面静止杂波的表观运动，得到目标对杂波的
水平径向速度差。这样本机向目标飞行时，横切目标仍能进入杂波滤波区。
只有目标较低且俯视角达到门限时才降低探测概率及测量质量；视距、RCS、ECM
和标称距离不变。因子随速度差连续变化，出区恢复到 1，不保证完全隐身。
航迹仍按原规则老化，半主动照射会受后续航迹质量和新鲜度影响。

这是空中搜索雷达的平面地面/海面近似，未增加地形遮挡、PRF、垂直多普勒、
独立导引头滤波或舰载雷达能力声明；不能把所有 beam/crank 都描述为必然脱锁。
`npm run verify:radar-doppler` 使用实际目录参数验证横切、接近、远离、移动雷达、
俯视门限及未配置传感器的兼容性。
